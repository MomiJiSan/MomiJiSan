### 01 &nbsp; / &nbsp; 关于我

喜欢把灵感做成可以运行、可以交互的小作品，让工具更顺手，让故事多一点可能。

- **陪伴** &nbsp; 让 AI 的对话、感知与日常交互连接起来。
- **故事** &nbsp; 探索视觉小说与 AI 角色相遇的体验。
- **工具** &nbsp; 将重复的操作变成更自然的工作流。
